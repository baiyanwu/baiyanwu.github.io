## 计划中的首页

做一个导航页，读取本账号下 pinned 的仓库并渲染为入口卡片：

- 该仓库已有项目站 → 跳转到对应的项目站（如 <https://baiyanwu.github.io/CoinMonitor/>）
- 该仓库没有项目站 → 跳转到 GitHub 仓库地址
- 私有仓库的 pinned 项对访客无意义，不展示

## 说明

- 本仓库是 GitHub Pages **用户站**，仓库名必须保持 `baiyanwu.github.io`，改名会导致站点地址失效。
- 已有的项目站（例如 `/CoinMonitor/`）与本站互不影响：项目站挂在 `/仓库名/` 子路径下，本站占用根路径。
